## ✨ Overview
The **Victory Free WiFi Portal** is a web application designed to provide secure and managed internet access for the community.  
It allows administrators to control bandwidth, monitor users, and ensure fair usage of free public Wi‑Fi.

---

## ⚙️ How It Works
- Citizens connect to the **Victory Free WiFi** SSID.  
- They are redirected to a **login/landing page**.  
- Authentication is handled via **voucher codes or user accounts**.  
- Administrators can monitor sessions, generate reports, and manage system users.
